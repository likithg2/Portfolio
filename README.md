# Likith .G — Personal Portfolio

A modern, animated personal portfolio built with **React + Vite**. Features a glassmorphism design, scroll-driven animations, and a fully responsive layout for both desktop and mobile.

## 🚀 Tech Stack

- **React 19** + **Vite**
- **Vanilla CSS** — glassmorphism, animations, responsive design
- **react-icons** — icon set
- **Google Fonts** — Poppins, Dancing Script

## ✨ Features

- Animated pill-style desktop navbar with scroll-tracking active state
- Mobile hamburger menu with smooth slide-in drawer
- Scroll-reveal animations for sections
- Typewriter hero text animation
- Glass-card project showcase with hover focus effect
- Fully responsive for all screen sizes

## 📂 Featured Projects

### 1. AgriShield
A full-stack smart agriculture platform to reduce post-harvest crop losses via AI-powered quality analysis and supply-chain optimization. Uses a fine-tuned MobileNetV2 model to assess vegetable freshness, shelf life, and financial loss, with route optimization, cold-storage recommendations, a Gemini chatbot, and English/Kannada voice advisory.

**Tech:** Python, FastAPI, TensorFlow/Keras, MobileNetV2, React, Vite, Tailwind CSS, SQLite, REST API, Gemini, OpenWeather API, Leaflet.js

### 2. NutriVision AI
An AI-powered nutrition and kitchen inventory platform that analyzes food images using Google Gemini Vision to identify nutritional information and track macros. Manages kitchen inventory, generates personalized recipes and smart shopping lists, and provides automated expiry alerts to reduce food waste.

**Tech:** React, Tailwind CSS, Framer Motion, Node.js, Express, Sequelize, Google Gemini AI, REST API, JWT, CRON

### 3. PiConnect
An Android application for wireless Raspberry Pi control and file management, eliminating the need for physical peripherals. Supports bi-directional Wi-Fi file transfer, SSH command execution, live file-system browsing, Bluetooth HID keyboard mode, and built-in PDF/audio/image viewers.

**Tech:** Kotlin, Android SDK, XML, SSH, Bluetooth HID, Wi-Fi, Network Programming
